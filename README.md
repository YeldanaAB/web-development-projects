
# Web Development Projects

A collection of web development projects completed as part of my Computer Science coursework at Toronto Metropolitan University. These projects explore HTML5, CSS, responsive web design, JavaScript programming, and interactive user interfaces.

## Technologies Used

- **Languages:** HTML5, CSS3, JavaScript
- **CSS Frameworks:** Bootstrap 5, Tailwind CSS
- **JavaScript Libraries & Frameworks:** jQuery, React, Vue.js, Alpine.js
- **Tools:** Git, GitHub, VS Code, FileZilla (SFTP)

## Projects

### 1. Columbia River Website

**Folder:** `columbia-river/`

An informational webpage about the Columbia River built using HTML5 and inline CSS.

- Structured content using semantic HTML5 elements, including `header`, `main`, `article`, and `footer`.
- Applied inline CSS for typography, colors, spacing, and layout.
- Incorporated images, embedded media, and accessible image descriptions.

**[Live Demo](https://cs.torontomu.ca/~ybolatzh/lab01/lab01.html)**

### 2. Personal Website

**Folder:** `personal-website/`

A personal profile website featuring structured navigation and custom styling.

- Built page layouts using CSS Flexbox.
- Used CSS variables and custom fonts.
- Organized content using HTML and CSS.

**[Live Demo](https://cs.torontomu.ca/~ybolatzh/lab02/lab02.html)**

### 3. Shark Adoption Website

**Folder:** `shark-adoption/`

A responsive shark adoption website implemented using three different styling approaches.

- **Pure CSS:** Created responsive layouts using CSS Grid and media queries.
- **Bootstrap 5:** Implemented responsive cards and an interactive image carousel.
- **Tailwind CSS:** Built responsive layouts using utility classes and hover transitions.
- Explored different approaches to responsive design across mobile, tablet, and desktop screens.

**Live Demos:**

[Pure CSS](https://cs.torontomu.ca/~ybolatzh/lab03/lab03a.html) |
[Bootstrap](https://cs.torontomu.ca/~ybolatzh/lab03/lab03b.html) |
[Tailwind CSS](https://cs.torontomu.ca/~ybolatzh/lab03/lab03c.html)

### 4. JavaScript Problems

**Folder:** `javascript-problems/`

Two client-side programming exercises developed using vanilla JavaScript.

- Built an event timeline using JavaScript `Date` objects, arrays, and date calculations.
- Calculated the number of days remaining until upcoming events or elapsed since past events.
- Implemented a palindrome checker using string sanitization and validation functions.
- Generated dynamic results with conditional formatting.

**[Live Demo](https://cs.torontomu.ca/~ybolatzh/lab04/lab04.html)**

### 5. JavaScript Framework Projects

**Folder:** `javascript-frameworks/`

Four interactive webpages demonstrating different JavaScript libraries and frameworks.

- **jQuery:** Implemented form validation, phone number formatting, and curved text effects.
- **React:** Built a live digital clock using `useState` and `useEffect`.
- **Vue.js:** Created an expandable image card with transitions.
- **Alpine.js:** Developed an interactive counter.
- Applied responsive styling to support different screen sizes.

**Live Demos:**

[jQuery](https://cs.torontomu.ca/~ybolatzh/lab05/lab05a.html) |
[React](https://cs.torontomu.ca/~ybolatzh/lab05/lab05b.html) |
[Vue.js](https://cs.torontomu.ca/~ybolatzh/lab05/lab05c.html) |
[Alpine.js](https://cs.torontomu.ca/~ybolatzh/lab05/lab05d.html)

## Deployment

All five projects were deployed to Toronto Metropolitan University's CS Moon server using FileZilla (SFTP).

Website files and assets were organized into separate directories, and each project was made publicly accessible through its live demo link.

## About

These projects helped me develop practical experience in front-end web development, responsive design, JavaScript programming, and component-based user interfaces.
